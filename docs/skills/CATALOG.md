# Skills do My House

As skills são arquivos `SKILL.md` para orientar desenvolvimento. Diretório: `.agents/skills/<nome>/SKILL.md`. Não instalam bibliotecas ou ferramentas.

## Fontes
- [BlockDOM (Block Doom)](https://github.com/kaina-visualsoftware/BlockDOM), diretório `.agents/skills` — UI, React, frontend, testes, segurança.
- [LibrasEdu](https://github.com/dev-oestagiario/LibrasEdu), diretório `.agents/skills` — acessibilidade, qualidade, privacidade e métodos de engenharia (inclui cópias historicamente originadas do BlockDOM).
- [QA-Hub](https://github.com/kaina-visualsoftware/QA-Hub), diretório `.agents/skills` — inspeção e revisão visual.
- [Capawesome Skills](https://github.com/capawesome-team/skills) — Capacitor com React e Android (MIT).
- [Three.js Skills](https://github.com/cesartevisual/threejs-skills) — React Three Fiber/Drei; conferir licença upstream.

## Política
- Copiar somente textos de skill e documentação atribuída; não executar ou importar scripts de terceiros automaticamente.
- A origem define a licença e limites. Conferir `SKILL.md` e repositório antes de redistribuir.
- Copiar skills não torna uma ferramenta instalada ou funcional; dependências são gerenciadas no `package.json`.
- Selecionar **as pertinentes** para cada tarefa pelo `AGENTS.md`. A existência de skills de outros domínios não muda a stack nem requisitos deste produto.
- Alguns `SKILL.md` originais referenciam `references/`, binários e dados não copiados: consultar a fonte quando necessário. Não afirmar que uma rotina foi executada sem evidências.

Atualizar o catálogo e conferir links/licenças ao acrescentar novos arquivos.
